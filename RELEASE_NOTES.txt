Chat+ 1.2.0

Minecraft Java 26.3. One JAR for Fabric Loader 0.19.5+ and the tested
Quilt Loader 0.31.0-beta.4 target. Mod Menu 21.0.0-beta.1 is optional;
Fabric API is not required.

Changes:
- Refreshed default appearance:
  transparent menus, outlined buttons, right-side channels, independent
  search/settings buttons, chat dimensions, animations, bubbles and player cards.
- Enabled mention styling by default, coloring only your name according to
  the approved profile. Mention audio remains enabled with Minecraft's bit
  sound, volume 0.6, pitch 1 and a one-second cooldown.
- Applied the eight shared Minecraft chat defaults once on a genuinely new
  Chat+ profile. Existing saved settings remain authoritative.
- Kept existing settings, personal rules, histories, player data and shortcuts.
  New installations and Reset use the same verified default profile.
- Avoided unnecessary component copies for ordinary messages when only
  mention styling is relevant; matching messages keep existing interactions.
- Added verified Quilt support using the same JAR as Fabric.
- Fixed missing interface icons and translations without Mod Menu or Fabric
  Resource Loader. No extra library is required.
- Reused custom server-filter regex matchers and released their message
  references after each match. Disabled server profiles skip unnecessary
  custom-pattern compilation.

Performance:
- The custom server-filter benchmark allocates 43.05% fewer temporary bytes
  than 1.1.0. Processing time is effectively unchanged in this workload.
- With mention styling enabled on both builds, the mention fast path allocates
  46.02% fewer temporary bytes without a mention and 26.86% fewer with a mention
  than 1.2.0-beta.1. Median processing time falls by about 18.3% in these tests.
- These targeted measurements do not imply whole-client FPS or RAM gains.

Updates preserve saved choices. Reset uses the new defaults but removes
configured channels/alerts; it is unnecessary for normal updates.
Histories/capacities and protected player data remain.

Verification: 39,724 checks across 64 suites. Fabric 0.19.5 and Quilt
0.31.0-beta.4 were independently checked with and without Mod Menu
21.0.0-beta.1, including 11 rendered screens, 35 resources and the effective
default settings. Automated checks do not certify authenticated Microsoft
exchanges or audible speech. Previous releases remain available.
